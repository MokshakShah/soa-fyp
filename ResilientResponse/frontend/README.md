# Frontend — Admin Dashboard

Desktop-only admin dashboard for ResilientResponse. Built with Next.js 14, TypeScript, and Tailwind CSS.

## Port: 3000

## Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React (icons)

## Run Locally
```bash
npm install
npm run dev
```

## Environment Variables
See `.env.local.example`

## Notes
- Desktop-only layout (min-width: 1024px enforced in CSS)
- Single role: ADMIN
- All pages are placeholders pending business logic implementation
